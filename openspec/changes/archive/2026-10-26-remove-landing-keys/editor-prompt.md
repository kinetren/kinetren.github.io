# Промпт для агента основного репозитория (kinetren)

Скопируй текст ниже в сессию агента в репозитории kinetren.

---

Перепиши `docs/guide/shortcuts.md` так, чтобы это был полный и аккуратный справочник
горячих клавиш и жестов мыши.

**Зачем.** Сайт kinetren.github.io показывает `docs/guide/*.md` как страницы `/docs/`.
Оттуда я убрал секцию «Клавиатура» с лендинга: справочнику там не место. Теперь
`shortcuts.md` — единственный справочник клавиш. Сейчас он беднее и некрасивее, чем был
лендинг: клавиши написаны жирным текстом, нет групп про регион и вид, а часть сочетаний
не упомянута совсем.

**Что сделать**

1. Мои слова запиши в `docs/user-feedback.md` по своим правилам до начала работы.
   Документацию пиши на английском. Название программы — строчными: kinetren.
2. Составь список всех сочетаний клавиш и жестов, которые программа реально обрабатывает.
   Источник — код: обработка клавиш в `src/apps/kt-app/src/` (`app.rs`, `timeline.rs`,
   `bin_panel.rs`, `automation.rs`, `pubparam.rs` и всё, что найдёшь по `Key::` и
   `key_pressed`), акселераторы меню (`Toolbar::menu_btn`) и строки подсказок в
   `i18n/en.toml`. Правило из `compositions`: клавиша описывается только там, где она
   действительно это делает.
3. Сверь список с тем, что было на лендинге (ниже). Каждую строку проверь по коду: если
   программа ведёт себя иначе, в документацию идёт поведение программы. Все расхождения
   перечисли в отчёте.
4. Сгруппируй таблицы по смыслу. Например: Transport · Editing · Region and markers ·
   Reels · View and zoom · Mouse on the timeline · Windows and panels (превью, таймкод,
   полосы скорости и громкости, фейдер). Лишние группы не придумывай: группа — это то,
   что пользователь ищет вместе. Формат каждой таблицы: `| Keys | Action |`.
5. Пиши клавиши как клавиши:
   - каждая клавиша и модификатор — `<kbd>…</kbd>`, сочетание через `+`:
     `<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>`;
   - альтернативы через ` / `: `<kbd>Delete</kbd> / <kbd>Backspace</kbd>`;
   - удержание, двойное нажатие, колесо и клики — словами рядом с капсами:
     `hold <kbd>Space</kbd>`, `<kbd>Ctrl</kbd>+wheel`, `double-click the timecode`;
   - действие — коротко, с маленькой буквы, без точки в конце, как сейчас.
6. Если текст других страниц guide (`timeline.md`, `getting-started.md`) противоречит
   новой таблице, поправь его. Ссылки между страницами оставь в виде
   `timeline.md#anchor`. Имя файла `shortcuts.md` не меняй.

**Markdown, который рендерит сайт** (всё остальное роняет сборку сайта): заголовки `#`,
абзацы, списки `-` и `1.` с одним уровнем вложенности, таблицы с `|` (внутри ячейки
пиши `\|`), блоки кода в ```, `**жирный**`, `*курсив*`, `` `код` ``, ссылки `[текст](путь)`,
картинки отдельной строкой и `<kbd>…</kbd>`. Нельзя: другой HTML, цитаты `>`, заголовки
с подчёркиванием `===`, ссылки-сноски `[x][y]` и `[^1]`, курсив через `_…_`,
обратные слэши, кроме `\|`. На GitHub `<kbd>` тоже рисуется капсами.

**Строки, которые были на лендинге** (каждую проверь по коду; формулировки не копируй):

- Transport: <kbd>Space</kbd> play/pause · второй тап — стоп, к началу региона ·
  hold <kbd>Space</kbd> — разгон до 4×, отпустить — замедление ·
  <kbd>A</kbd>/<kbd>D</kbd> и <kbd>Home</kbd>/<kbd>End</kbd> — предыдущий/следующий
  маркер, край региона или события · <kbd>Shift</kbd>+<kbd>Home</kbd>/<kbd>End</kbd> —
  самое начало/конец проекта · <kbd>Ctrl</kbd>+<kbd>L</kbd> — переход к введённому
  таймкоду
- Editing: <kbd>S</kbd> — разрезать на курсоре / вырезать регион · <kbd>Del</kbd> —
  удалить клип или всё в регионе · <kbd>Ctrl</kbd>+<kbd>C</kbd>/<kbd>V</kbd> — копировать
  клип или содержимое региона / вставить на курсоре цепочкой ·
  <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>,
  <kbd>Ctrl</kbd>+<kbd>S</kbd> · удерживать <kbd>Ctrl</kbd> при перетаскивании —
  без магнита
- Region and markers: <kbd>I</kbd>/<kbd>O</kbd> · <kbd>Shift</kbd>+<kbd>A</kbd>/<kbd>D</kbd>
  — прыжок с перетаскиванием края региона · <kbd>L</kbd> — луп ·
  <kbd>M</kbd> — поставить/снять маркер · <kbd>Esc</kbd> — шаг назад (закрыть верхнее
  окно, снять регион и выделение, выйти из ролика) · <kbd>Ctrl</kbd>+<kbd>F</kbd> — поиск
- View: колесо — прокрутка таймлайна · <kbd>Ctrl</kbd>+колесо — зум по времени ·
  <kbd>Shift</kbd>+колесо — прокрутка дорожек · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+колесо —
  высота дорожек · двойной клик по превью — вынести в отдельное окно · двойной клик по
  таймкоду — ввести позицию · двойной клик по полосе скорости, рейке громкости, фейдеру —
  сброс

Что уже есть в guide и должно остаться: <kbd>Alt</kbd>+<kbd>M</kbd>/<kbd>S</kbd>,
<kbd>Enter</kbd> на ролике, <kbd>Ctrl</kbd>+<kbd>Y</kbd>, все жесты мыши на таймлайне.

**Готово, когда:** `shortcuts.md` перечисляет все обрабатываемые сочетания, каждое
сверено с кодом; страница нормально выглядит на GitHub; изменение закоммичено по правилам
репозитория. В отчёте: список расхождений с лендингом и фраза «на сайте: скажи "обнови"
в kt.9.site».
